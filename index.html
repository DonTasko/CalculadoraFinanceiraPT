    Política de Privacidade

    A Calculadora Financeira PT não recolhe dados pessoais. Não pedimos email, nome ou telefone.

    Todos os cálculos e o histórico são guardados apenas no seu dispositivo (localStorage).

    Funcionalidades futuras de publicidade (AdMob) podem enviar dados anonimizados para a Google, conforme a política da Google Play.

    A aplicação funciona offline. A internet só é necessária para carregar anúncios, quando ativados.

    Sobre

    Calculadora Financeira PT é uma aplicação de utilidade diária para utilizadores em Portugal.

    Reúne as principais calculadoras financeiras num único local, com interface simples e rápida.

    Os valores apresentados são estimativas e não constituem aconselhamento financeiro ou fiscal.
